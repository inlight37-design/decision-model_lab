## 기록 원칙

- 공식 문서, 프로젝트 저장소, 모델 카드 등 원문 출처를 우선합니다.
- 프로젝트가 자체적으로 발표한 성능 수치는 **자체 보고(self-reported)** 로 표시합니다.
- 서로 다른 하드웨어·데이터셋·실행 조건의 수치를 직접적인 우열 비교로 해석하지 않습니다.
- 아직 공개되지 않은 내부 구조는 추정으로 단정하지 않습니다.
- 조사 내용은 공개 자료가 갱신되면 변경될 수 있습니다.
