승격에 쓸 수 있는 근거

testpassed sourcepassed calculationpassed

해결되지 않은 것

testfailed sourceinconclusive testskipped sourcedenied

승격 불가 — passed 여도 긍정색이 아니다

votepassed self_reportpassed

모델 두 개가 동의한 vote:passed 와 테스트가 통과한 test:passed 는 같은 글자지만 다른 근거다. checker 가 supported 승격에서 vote 와 self_report 를 세지 않으므로 화면도 같은 구분을 유지한다.

kind 를 접거나 아이콘으로 바꾸지 않는다. passed 만 남기면 화면이 거짓말을 한다.

skipped 는 빈칸이 아니라 파선으로 그려 "검사하지 않음"을 남긴다. failed 는 테두리가 두껍고 접힌 상태에서도 보인다.
