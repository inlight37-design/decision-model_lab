# tools/w2 — 격리 백엔드(bubblewrap) 관측

| 파일 | 무엇 |
|---|---|
| [`cli_boundary.py`](cli_boundary.py) | 설치된 Claude Code·Codex를 [`core/isolation.py`](../../core/isolation.py)의 참여자 경계 안에서 실행한다. `--version`, 로그인 상태(모델 호출 아님), 다른 CLI 인증·HOME·`/mnt/c`가 보이는지. 계정 이메일·조직 ID·요금제는 출력에서 버린다. WSL·Linux에서 저장소 루트로 `python3 tools/w2/cli_boundary.py` |
| [`auth_mounts.py`](auth_mounts.py) | N3(K09). 인증·설정 연결 조합을 바꿔 가며 격리 안에서 `--version`과 로그인 상태만 실행한다 — 모델 호출 없음. 좁힌 조합은 모두 읽기 전용. 이메일·긴 토큰 모양 문자열은 출력에서 지운다. 결과: [auth-mounts-aux-pc-wsl.md](../../docs/experiments/w2-isolation/auth-mounts-aux-pc-wsl.md) |
| [`observe.py`](observe.py) | 2단계 관측(tier 2, B1·B2). [`CliExecutor`](../../app/cli_executor.py)와 같은 argv·격리 경계로 실제 CLI를 한 번씩 부른다 — **모델 호출**. `plan`(호출 없음), `approve`(사용자 승인의 provider별 상한·timeout·메모), `status`, `call <probe> <전체 모델 이름>`. 승인이 없거나 상한을 다 썼거나 앞 호출이 기대와 달랐으면 부르지 않는다. `k46-codex`는 모델이 돌린 명령이 Codex 로그인 파일을 열 수 있는지 종료 코드로 본다(K46). `--keep-session`(Codex만)은 세션 기록을 남기게 해 상태 폴더로 옮기고 그 모양만 요약한다(C3 (a)). 원 출력은 저장소 밖 `~/.local/state/dml-observe/`. 요약은 파일 이름·stderr의 UUID, 긴 16진수 ID, 토큰 모양(JWT 등)을 가리지만 옮기기 전에 한 번 더 읽는다. 답이나 출력에 JWT가 보이면 경계 위반으로 멈춘다. WSL에서는 로그인 셸(`bash -l`)에서. 결과: [stage2-aux-pc-wsl.md](../../docs/experiments/w2-isolation/stage2-aux-pc-wsl.md) |
| [`codex_sandbox.py`](codex_sandbox.py) | K12·K09·K46. 참여자 경계 안에서 `codex sandbox -- /bin/sh -c …`로 Codex 자체 Linux 샌드박스가 중첩돼 서는지, 작업 폴더 쓰기를 막는지, 명령이 `~/.codex/auth.json`을 읽을 수 있는지(종료 코드만), 밖으로 연결을 열 수 있는지 본다. 인증 파일 읽기를 금지하는 권한 profile 변형도 함께 돈다 — 모델 호출 없음. exec가 모델의 명령을 돌린 관측은 아니다. 결과: [K12](../../docs/experiments/w2-isolation/stage2-aux-pc-wsl.md), [K09·K46](../../docs/experiments/w2-isolation/stage2-followup-aux-pc-wsl.md). 이 도구의 profile은 `-P`로 고른다 — `codex sandbox`에만 있는 옵션이고 exec에는 없다([정정](../../docs/experiments/w2-isolation/k46-profile-aux-pc-wsl.md)) |
| [`codex_profile.py`](codex_profile.py) | K46. adapter가 넘기는 권한 profile(`core.adapters.codex_permissions`)을 모델 없이 본다. (1) `codex sandbox`에 exec와 같은 방식(`default_permissions`)으로 줘서 명령이 인증 파일을 못 여는지. (2) 참여자의 실제 exec argv를 **네트워크 없는** 격리(`--share-net`만 뺌)에서 돌려 설정을 받아들이는지, 없는 profile 이름을 연결 전에 거절하는지. 인증 파일은 크기·수정 시각만 비교한다. exec에서 모델의 명령에 금지가 적용되는지는 `observe.py k46-codex`가 본다. 결과: [k46-profile-aux-pc-wsl.md](../../docs/experiments/w2-isolation/k46-profile-aux-pc-wsl.md) |

합성 파일 경계 시험은 도구가 아니라 회귀 시험([`tests/test_core_isolation.py`](../../tests/test_core_isolation.py))이다. 결과: [docs/experiments/w2-isolation/](../../docs/experiments/w2-isolation/aux-pc-wsl.md).
