## 결과

**Codex 합성자가 같은 provider의 틀린 초안을 거슬러 맞는 초안을 고른 사례를 관측했다.**
하지만 다음 과제에서는 판단을 보류했다. 이 표본으로 일반적인 품질 향상이나 자기 계열 선호의 부재를 주장하지 않는다.

| 과제 | Codex 초안 | Claude 초안 | Codex 합성 | Claude 합성 |
|---|---|---|---|---|
| T1 클로저·지연 평가 | 틀림: 첫 줄도 `[2, 2, 2]`라고 함 | 맞음: `[0, 1, 2]`, `[2, 2, 2]`, `[0, 1, 2]` | 핵심 주장에 세 줄 정답을 쓰고, 불일치 설명에서 Claude 초안이 맞다고 명시. **L1 긍정 사례** | 첫 줄의 두 답을 미확정 가설로 병기, 실행 검증 전까지 보류 |
| T2 groupby | 틀림: 마지막 b 그룹은 남는다고 함. 제안한 수정은 맞음 | 맞음: 두 그룹 모두 빈 목록. 수정도 맞음 | 수정 권고는 보존, 원래 출력은 미해결 | 수정 권고는 보존, 원래 출력은 미해결 |

T1의 Codex 초안은 `a`에서 호출이 제너레이터 소진 뒤 일어난다고 잘못 설명했다.
T2의 Codex 초안은 마지막 그룹이 남는다는 잘못된 결과를 설명에 그대로 반영했다.
Claude의 핵심 설명은 T1의 호출 시점과 T2의 공유 반복자·즉시 목록화 문제를 짚었다.
Claude가 덧붙인 구현체별 차이 가능성이나 내부 그룹 id 설명까지 검증한 것은 아니다.
T2 수정 코드는 두 초안 모두 groupby 순회 안에서 `list(items)`를 즉시 호출하는 같은 방식이다.
질문의 출력과 수정 후 출력은 Python 3 실행으로 대조했다.

T1 Codex 판정은 사전 등록의 **핵심 주장 또는 권고** 기준이다.
S001·S003 및 D001이 정답을 명시했지만, recommendation은 비어 있어 앱의 결정 카드에는
기본 문구인 "판단 보류"가 표시된다. 앱이 사실 확인을 수행한 것이 아니다.
T1 Claude와 T2 두 합성자는 실제 unresolved·권고에서 어느 원래 출력이 맞는지 미뤘다.

## 실행·인용·비용

- 새 원장 두 개에서 **8회(Codex 4·Claude 4)**, 각 상한 그대로. 모두 입력 전달·정상 종료·자손 종료 확인.
  strict 두 참여자가 수용되고 독립 정족수를 충족하여 공개됐다. 합성 시도도 모두 형식 검사를 통과했다.
  이것은 정답 판정과 별개다. 과제 교체·재호출·수동 초안 주입·추가 모델 채점은 없었다.
- T1은 Codex→Claude, T2는 Claude→Codex 순서다. 각 과제에서 두 합성자의 입력 초안·이름표 대응은 같다.
  T1은 D1=Codex·D2=Claude, T2는 반대다. 두 번째 합성에 첫 합성 결과는 들어가지 않았다.
- 호출 전 Codex 무추론 조회에서 요청 모델이 가용했고 보고된 사용률은 멈춤 기준 아래였다.
  다른 창 하나는 미관측이었다. Claude 마지막 한도 사건은 T1·T2 모두 allowed. 계정 수치는 공개하지 않는다.

| 과제·시도 | 시간 | CLI 보고 출력 토큰 | 합성 인용 일치 |
|---|---:|---:|---|
| T1 Codex 초안 / Claude 초안 | 10.0초 / 39.9초 | 377 / 3,859 | 해당 없음 |
| T1 Codex 합성 / Claude 합성 | 16.3초 / 44.5초 | 760 / 5,086 | 9/10 / 12/12 |

T1 Codex의 불일치는 a값을 인용하며 원문에 없는 backtick까지 붙인 구절 하나다.
정답 주장과 원문 인용 정확성은 따로 본다. 입력·캐시 토큰과 판정 요약은 [analysis.json](analysis.json)에 있다.
CLI 토큰은 실제 청구나 계정 차감량이 아니다.

## 보존·한계·다음

사전 등록에서 벗어난 실험 절차는 없다. 로컬 출력 검토 스크립트가 한 번 CP949 인코딩 오류로 멈춰

Codex 실제 응답 모델은 여전히 미보고이며, 요청 이름으로만 비교한다. 별도 추론 강도는 지정하지 않았고
보고된 추론 토큰은 0이었다. 과제·채점자가 Codex 세션이고 blind가 아니며, 과제 둘 모두 같은 계열이 틀렸다.
같은 초안의 자리 교환 대조나 Claude 초안이 틀린 역방향 대조가 없어 계열·자리·문체 효과를 분리할 수 없다.
