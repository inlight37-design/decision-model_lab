# 채점 기준 — Q7·Q8 (2026-10-08 사전 등록)

항목마다 0 또는 1, 답 하나의 합은 0–5다. 답 이름(무작위)만 보고 채점하며, 어느 조건·모델의 답인지는 채점을 커밋하기 전에 보지 않는다. 판단의 이유를 한 줄씩 적는다.

## Q7 데이터 보관

| 항목 | 1점 조건 |
|---|---|
| C1 충돌 | 조건 1(30일 안 복구 불가 삭제)과 조건 2(1년 WORM 백업)가 평문 개인정보가 든 백업에서 서로 부딪친다는 것을 짚는다 |
| C2 해결 | 충돌을 푸는 방법이 실제로 통한다. 예: 회원별 키로 개인정보를 암호화하고 키를 WORM 밖에 두어 탈퇴 때 키를 지우기(crypto-shredding), 개인정보를 WORM 백업에서 분리하기, 또는 바꿀 조건을 하나 골라 어떻게 바꿀지 구체적으로 제안하기. 여러 방법을 늘어놓기만 하고 고르지 않으면 0 |
| C3 조용한 위반 없음 | WORM에서 지울 수 있다고 하거나, 백업을 삭제 대상에서 빼는 것을 위반이라고 밝히지 않은 채 권하는 식의 숨은 위반이 없다 |
| C4 다른 조건의 영향 | 고른 방법이 조건 4(1명·2주) 또는 조건 5(전체 복원)에 주는 영향을 하나 이상 구체적으로 다룬다. 예: 기존 평문 백업 1년치는 여전히 남는다, 복원한 DB에서 탈퇴 회원의 개인정보는 읽을 수 없다, 열 암호화 개조가 2주에 맞는지 |
| C5 뒤집을 조건 | 결론을 바꿀 구체적 조건을 쓴다(예: 법무가 "복구 불가 상태" 대신 "사용 불가 상태"를 인정하면) |

## Q8 회의록

|---|---|
| C1 모순 발견 | 11.0억에서 12.0억은 약 9.1% 증가이지 20%가 아니라는 것을 짚는다 |
