# 독립 검토 실행 안내

**넘길 파일은 [`SEND.md`](SEND.md) 하나뿐이다. 이 파일은 넘기지 않는다.**

이 파일에는 무엇을 왜 뺐는지가 적혀 있다. 상대가 그걸 알면 판단이 그쪽으로 끌려간다.

---

## 어떻게 넘기는가

| 상대 | 방법 |
|---|---|
| 웹 채팅 (ChatGPT, Gemini 등) | `SEND.md` **내용을 복사해 붙여넣기**. 파일 업로드도 가능 |
| CLI 에이전트 / IDE 확장 | 파일 경로를 주고 읽게 해도 된다 |

어느 쪽이든 **SEND 파일 하나로 끝난다.** 추가 설명을 덧붙이지 않는다. 덧붙이는 순간 그게 조건 차이가 된다.

---

## 왜 이 형태인가

`deliberate` 프로토콜의 `P1`은 **독립 초안**을 요구한다. 다른 모델의 답이나 부모의 결론을 초기 packet에 넣지 않는다(`D11`).

SEND 파일에서 의도적으로 뺀 것:

- **이 세션 AI가 어느 쪽으로 기울었는지** — 알려주면 그쪽으로 수렴하거나 일부러 반대로 간다. 둘 다 오염이다
- **"다른 AI가 이미 답했다"는 사실** — 비교 대상이 있다는 것만 알아도 차별화 압력이 생긴다
- **Orca / AionUi / ACP의 우열** — 순위 없는 사실 목록으로만 넣었다

빼지 않은 것: 확정된 제약(`D11`, `D12`, `D15`, `D16`), 유지보수자 1인 조건, 확인된 라이선스·규모. 이건 모든 참여자가 같은 버전으로 받아야 하는 공통 자료다(`P0`).

## 실험 조건 기록 (`P0`)

| 항목 | 값 |
|---|---|
| 독립 web 조사 | **허용**. 고정 source pack 비교와는 **다른 조건**이라는 점을 기록해 둔다 |
| 공통 제공 자료 | 공개 저장소 링크 + 확인된 사실 6항목 |
| 요구 출력 | `answer` / `claims` / `assumptions` / `evidence_refs` / `counterexamples` / `unknowns` / `checks_proposed` |
| 라운드 | **0** (초안만). 교차검토가 필요하면 별도 라운드로 |

## 이번에 묻지 않은 것

**Q1(어댑터 전송 — ACP vs 직접 exec)은 제외했다.** 답이 `V04-01` 인벤토리 결과에 달려 있다. 어떤 CLI가 실제로 깔려 있고 무엇을 지원하는지 모르는 상태에서 물으면 근거 없는 의견만 돌아온다. `D12`의 "acceptance 없는 사실 수용은 보류"가 이 경우다. 인벤토리 후에 묻는다.

SEND 파일의 질문은 **1–4로 새로 번호를 매겼다.** 처음 보는 쪽에게 "Q1은 어디 갔지"를 만들지 않기 위해서다.

## 답을 받은 뒤

1. 답변을 **그대로 보존한다.** 요약해서 덮어쓰지 않는다 (`P1`)
2. 이 세션의 답과 **주장 단위로** 대조한다. 결론이 같은지가 아니라 **근거가 같은지**를 본다 (`P2`)
3. 두 쪽이 합의해도 근거가 없으면 `unresolved`로 남긴다 (`D12`). **합의는 검증이 아니다**
4. 해결되지 않은 차이를 최종 결정에 남긴다. 다수결로 지우지 않는다

한 곳 이상에 보냈다면 각각의 답을 따로 보존하고, 제시 순서를 기록한다. 같은 답이 여러 번 나왔다는 사실은 관측값이지 근거가 아니다.
