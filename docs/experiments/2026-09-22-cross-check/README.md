# 실험 기록 — 첫 실전 cross_check (2026-09-22)

이 저장소가 설계한 `cross_check` 모드를 **처음으로 실제 문제에 적용한** 기록. 대상은 합성 기록이 아니라 남아 있던 설계 결정이었다.

`P1`은 초기 답변을 그대로 보존하라고 요구한다. 그래서 참여자 B의 답변을 요약하지 않고 원문 그대로 둔다.

## 파일

| 파일 | 무엇 |
|---|---|
| [`SEND.md`](SEND.md) | 참여자에게 **실제로 보낸 것.** 이것 하나만 전달했다 |
| [`PROTOCOL.md`](PROTOCOL.md) | 무엇을 왜 뺐는지. **참여자에게 보내지 않았다** — 알면 판단이 끌려간다 |
| [`RESULT-participant-B.md`](RESULT-participant-B.md) | 참여자 B의 답변 원문 |

참여자 A의 답변은 이 저장소를 수정한 세션 자체다. 별도 파일로 남기지 않았고, 그 결론은 [`REVIEW_FIXES.md`](../../architecture/v0.4/REVIEW_FIXES.md) §6에 정리돼 있다. **이것은 기록의 비대칭이며, 다음 실험에서는 양쪽 초안을 같은 형식으로 남겨야 한다.**

## 조건 (`P0`)

| 항목 | 값 |
|---|---|
| 참여자 | 서로 다른 provider의 상급 모델 2인 |
| 공통 입력 | `SEND.md` 단일 파일 |
| blind | 상대의 결론·기울기를 전달하지 않음. "다른 AI가 답했다"는 사실 자체도 제외 |
| 독립 web 조사 | **허용** — 고정 source pack 조건과 다른 실험 조건 |
| 라운드 | 0 (초안만) |

## 관측된 프로토콜 문제

1. **공통 입력의 오류는 모두에게 전파된다.** `SEND.md`에 틀린 사실이 둘 있었다 — ACP 과금 정보, Paseo 라이선스. `P0`의 "같은 버전으로 제공한다"는 **같은 오류를 함께 받는다**는 뜻이기도 하다.
2. **빠진 선택지는 반례가 나올 수 없다.** herdr를 목록에 넣지 않아 양쪽 다 검토하지 못했다.
3. **합의가 근거를 뜻하지 않는다.** 의존 범위에서 양쪽이 같은 결론에 도달했으나 코드를 읽은 것은 한쪽뿐이었다.
4. **locator를 정확히 따라가지 않으면 옳은 주장을 기각한다.** `--bare` 건은 첫 조회 페이지에 없어 기각할 뻔했다.

## 이 실험이 증명하지 않는 것

**cross_check가 단독보다 낫다는 증거가 아니다.** 대조군 없이 한 번 실행했을 뿐이다. 판정은 [Q0–Q7 비교 실험](../../architecture/v0.4/03-evaluation-and-roadmap.md) 몫이다.
