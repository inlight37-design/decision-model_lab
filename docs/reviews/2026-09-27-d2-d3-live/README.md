**D2(다음 단계 제안).** 원문 모드에 Claude를 슈퍼바이저로, Claude·Codex를 격리 팀원으로 뒀다. 공개 뒤 제안은 정해진 JSON 하나로 "여기서 끝"을 냈다 — 두 답의 결론·근거·뒤집을 조건이 같아 더 물을 새 관점이 적다는 이유와 남은 쟁점 두 개(실제 문서량·질의 기록 확인, 관리형 서비스 비용 조사). 슈퍼바이저에게 보낸 입력에는 회사·카드 이름이 없었다(이름표 D1·D2만). 작업의 쓴 호출 수는 3(팀원 2 + 제안 1)이었다.

**D3(분담 제안).** 일반 칸에 Claude·Codex, 오케스트레이터 칸에 Claude(팀원과 같은 카드), 가상 자료 두 개(검색 실패 로그, 벡터 검색 견적)를 뒀다. 분담 제안은 목표의 "문제 크기"와 "비용"을 나눠 로그는 Claude에게, 견적은 Codex에게 주는 JSON 하나였고, 모든 자료가 누군가에게 갔으며 나눈 이유를 적었다. 화면이 팀원별 칸을 그대로 채웠고, 고치지 않고 시작해 실행에 "제안대로"가 남았다. 두 팀원은 각자 받은 파일만 근거로 들었다. 작업의 쓴 호출 수는 3(분담 1 + 팀원 2)이었다.
