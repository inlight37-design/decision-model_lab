## 사용자 요청과 유지할 전제

NEXT-SESSION.md와 v0.4 HANDOFF를 읽고 시작했다. 하나의 앱을 통째로 채택하지 않고 Orca·Paseo·herdr 및 추가 사례의 유용한 패턴을 추출한다. Python 코어, native 구독 CLI 우선, 상급 모델 독립 추론과 근거 검증, 읽기 전용 논의자, opt-in 없는 유료 API 전환 금지를 유지한다. Q4 첫 화면은 아직 미확정이다.

## 진행 순서

1. MCP/ACP/native adapter 경계를 공식 문서와 대조한다.
2. 기존 앱에서 추출할 패턴과 가져오면 안 되는 권한/운영 가정을 분리한다.
3. Ledger 소스와 현재 검사 범위를 검토한다. 완성 앱이나 실모델 연결로 오인시키지 않는다.
4. 기기별 CLI 인벤토리를 날조하지 않고, 오프라인에서 검증 가능한 작은 보완을 구현한다.
5. 검사 결과와 다음 작업을 저장하고 PR에서 변경을 모아 본다.

## 먼저 확인한 정정 후보

herdr의 현재 README는 클라이언트 종료/SSH 단절 시 서버의 프로세스 유지와 **서버/기기 재시작 후 배치 복원 및 지원 세션 resume**을 구분한다. 원래 프로세스는 재부팅을 넘어 생존하지 않는다. NEXT-SESSION의 '세션이 재부팅을 넘어 생존'을 운영상 프로세스 생존 보장으로 읽으면 안 된다.

원문: https://github.com/herdrdev/herdr (README, 확인 2026-09-23). 공식 프로젝트의 설명을 읽은 것이며 사용자 Windows 기기에서 재현한 결과가 아니다.

현재 대화 컨테이너에서 공개 저장소 git clone은 DNS 오류로 실패했다. 읽기/원격 저장은 GitHub connector를 사용한다. 사용자 PC의 C:\\ai 경로에 접근하거나 CLI 설치·인증을 확인한 것은 아니다. 아직 새 실행 결과를 주장하지 않는다.
