## B. 일부러 심은 오류 — 잡는가

새 원장(`dml-planted-20260927`, 상한 Claude 2·Codex 1, Codex는 쓰지 않음). 격리 칸에 Claude(CLI)와 원본 앱 칸(ChatGPT 앱)을 두었다. 원본 앱 칸에는 **이 세션이 직접 쓴 답**을 넣었다 — 실제 ChatGPT의 답이 아니다. 그 답에 두 오류를 심었다.

## 읽는 법

- 이번 두 번에서 교차검토는 **없는 오류를 지어내지 않았고**(A), **심어 둔 오류 둘을 모두 잡았다**(B).
- 검토자는 자료 원문을 받지 않는다. B에서 잡은 것은 자기 답과 상대 답이 어긋나는 곳이었다 — **검토자 자신이 자료를 바르게 읽었기 때문에** 가능했다. 두 답이 같은 방향으로 틀리면 이 방식으로는 잡기 어렵다.
- 심은 오류는 쉬운 편이다(숫자 하나, 분류 모순 하나). 미묘한 오류, 긴 답, 여러 오류가 섞인 경우는 보지 않았다. 표본은 한 번씩이다.
- 인용 일치는 여기서도 "그 문장이 대상 답에 있다"는 뜻일 뿐이다. 지적이 맞는지는 사람이 처분으로 정한다.
- 결과 모으기(D4)에는 검토 단계가 없다. 일반 작업에서도 이런 확인이 필요하면, 교차검토를 일반 작업에 붙이는 것은 새 카드로 연다.
