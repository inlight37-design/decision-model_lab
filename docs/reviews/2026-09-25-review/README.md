2. **#70·#71은 고칠 실행 문제다.** #70은 초안뿐 아니라 메타데이터의 잘못된 Unicode와 종결 상태를 함께 다뤄야 한다. #71은 기기 이름표만 비교하는 대신 저장소 밖 로컬 환경 등록과 실제 관측을 연결하고, C3 완화 모드에서도 다른 환경의 관측을 빌려 쓰지 못하게 해야 한다.
3. **프레임워크 확대보다 경계 수정 뒤 작은 L1 실험을 권고한다.** 최근 실행 구조는 확인한 범위에서 기존 소유권·원장 안에 머문다. 합성의 일반적 이득과 카드 보드의 정식 채택은 아직 입증되지 않았다. 비교 실험의 조건·비용·실패 분모를 사전 등록하는 편이 우선이다.

검토 중 PR #74가 다시 수정되어 **`2450caff5b3bf58eabee5d2486ba7a294c63dd89`**로 main에 병합됐다. 새 설치판의 원문과 변경 목록을 다시 읽어 [추가 대조](UPSTREAM-UPDATE.md)를 남겼다. 특히 새 `setup.ps1`이 고친 WSL 설치 오류 처리를 옛 R01과 구분했다. 최신 Windows 설치 경로 전체를 실행하거나 검증 완료로 승인한 것은 아니다.

**읽는 순서: 이 파일 → 최초 검토 전문 → 추가 대조 → 재현 결과.** 최초 전문의 파일명·행 번호는 최초 판에 관한 것이다. 삭제된 옛 Windows 파일은 해당 판으로 링크를 고정했고, 다른 소스도 그 판에서 보려면 [최초 완료 커밋의 원문](https://github.com/inlight37-design/decision-model_lab/blob/25f6595cb16985a6e41bc826f94af611842aaaf9/docs/reviews/2026-09-25-review/README.md)에서 열거나 추가 대조의 판 고정 링크를 사용한다.

## 재현과 보존된 진행

[probe.py](probe.py)와 [최초 실행 결과](probe-results.json)를 함께 제공한다. 재현 스크립트는 원격 파일과 로컬 실행 파일의 blob SHA가 **`13d6e17ef4123916f93ef1c91f89ff11eacf8629`**로 같음을 확인했다. 마지막에 다시 실행한 결과도 최초 로컬 JSON과 바이트가 같았고, Python 컴파일 검사와 원본 셸의 `bash -n`은 종료 0이었다. 이것은 전체 앱 시험이 통과했다는 뜻이 아니라 문서에 적은 경계 현상을 재현했다는 뜻이다.

최신 코드에서도 최초 실험을 다시 볼 수 있게 `fixture-source/`에는 최초 설치 원문 두 개를 **원래 Git blob 그대로** 보존했다. 이 파일들은 설치용이 아니라 아래 대역 시험의 입력이다. 이 폴더의 설치 셸을 직접 실행하지 않는다.

```sh
python docs/reviews/2026-09-25-review/probe.py --root docs/reviews/2026-09-25-review/fixture-source
```

스크립트는 원본 해시를 검사한 뒤 Python 함수의 입력 대역, 임시 디렉터리의 셸과 무해한 명령 대역만 쓴다. 인증 값·사용자 원장·네트워크·설치·실제 CLI·모델 호출에 접근하지 않는다. `probe-results.json`의 `checkpoint_next`는 최초 중간 커밋 때의 재개 메모이고 최종 미완료 목록이 아니다.

초기 범위 `3e007f1`, 재현 결과 `c45f1f2`, 재현 코드 `f878689`, 최초 전문 `25f6595`, 인계 `3848da9`, 동시 수정된 새 판 대조 `735c42c`, 새 인계와의 조정 `caa0346`을 원격에 순서대로 남겼다. 최종 head와 CI는 PR Checks/카드 #73 댓글이 기준이다. 검토 브랜치에 이미 병합된 main을 가져와 인계 충돌을 정리하되, **이 검토 PR을 main에 병합하지 않는다.** 제품 코드는 최신 main 그대로 보존한다.

## 확인하지 못한 것

GitHub 연결과 별도 Linux 웹 컨테이너만 사용했다. 사용자 PC, 깨끗한 Windows/WSL 설치, PowerShell 실제 실행·재부팅 재개·로그인, 전체 controller의 추가 #70 경로, 실제 모델 비교, 실제 브라우저, systemd/네트워크 실험은 하지 않았다. 컨테이너의 Git clone은 DNS 실패로 중단되어 전체 로컬 시험을 수행하지 못했다. 기존 세션의 실제 PC 기록은 그 세션의 관측으로 보존한다.

기본 도구 의미는 최초 전문에 적은 Microsoft PowerShell/WSL, GNU Bash, Python json, systemd의 공식 문서로 대조했다. 코드 관측·이전 문서·직접 재현·설계 제안을 구분했다. 추가 모델/구독 CLI 호출은 **0**이다. 정확한 최종 head의 GitHub Actions 결과를 보기 전에는 CI 통과로 쓰지 않는다.
