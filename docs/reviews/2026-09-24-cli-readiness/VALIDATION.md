# 최종 검증

전체 검사를 진행 중이다. Windows·WSL의 첫 통합 실행은 제품 시험에서 추가 실패가 없었지만, 동시에 작성 중이던 `GITHUB-C3.md`의 상대 링크 대상이 아직 없어 문서 검사에서 실패했다. 문서 작성 완료 뒤 최종 커밋에서 다시 전체 검사한다. Windows 임시 검사 harness의 실패 로그 출력도 CP949 오류가 있어 UTF-8로 고쳤다(제품 코드 아님).

정확한 head의 CI는 이 브랜치의 push run과 두 job의 checkout SHA를 확인한 뒤 여기에 기록한다. 확인 전에는 최종 통과로 주장하지 않는다.
