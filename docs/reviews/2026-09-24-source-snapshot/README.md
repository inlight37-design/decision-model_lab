# 공통 자료 스냅샷(B)과 A·F의 실제 확인 — 2026-09-24

claude 세션이 [인계 4절](../../../NEXT-SESSION.md)의 B를 구현하고, 실제 Codex·Claude 실행 한 번으로 B와 [A·F](../2026-09-24-account-limits/README.md)를 함께 확인했다.

## 작성·접근 범위

- `aux-pc`의 Windows(Python 3.12.6)와 WSL `aux-pc-wsl`(Ubuntu-24.04, Python 3.12.3, bubblewrap 0.9.0). WSL의 native Codex 0.156.1, Claude Code 2.1.280을 썼다.
- **모델 호출 2회**(Codex 1, Claude 1). 사용자 요청(“차례대로 진행하고…”)과 인계 2절 22의 승인. 구독 로그인만 썼고 유료 API·추가 크레딧은 없다. 계정 메타데이터 조회 1회(추론 없음, 화면의 Codex “조회”).
- 서버는 이 세션이 띄우고 끝낸 뒤 포트 닫힘·남은 프로세스 없음·원장 잠금 해제를 확인했다. 브라우저는 Claude 데스크톱 앱의 in-app 브라우저다.

## 1. 바꾼 것

| 부분 | 구현 |
|---|---|
| 받기·검사 | `POST /api/runs`의 `sources`는 `{name, text}`만 받는다. 이름은 영문·숫자·점·밑줄·하이픈(첫 글자는 영문·숫자), 경로 문자·숨김 이름·Windows 장치 이름·대소문자 무시 중복을 거절한다. 파일은 20개, 파일당 256 KiB, 합계 1 MiB, NUL 없는 UTF-8 글까지다. 화면은 고른 파일을 UTF-8로 읽고 이름을 이 규칙에 맞게 바꾼다 |
| 고정 | 원장 스키마 7의 `sources` 표에 내용·sha256·크기를 넣는다. 질문 본문에 목록(이름·크기·sha256)과 폴더 경로를 넣어 **입력 digest가 모든 파일을 묶는다**. `run_created` 사건에도 목록을 남긴다 |
| 제공 | 시도마다 원장의 사본을 데이터 폴더 밖(`<work_root>/_sources/<run>`)에 한 번에(임시 이름으로 쓴 뒤 이름 바꾸기) 두고, 목록·크기·sha256을 다시 맞춘다. 파일 추가·삭제·수정·링크면 그 시도를 **시작 전에** 거절한다. CLI 참여자는 provider별 빈 입력 폴더 대신 이 폴더 하나를 읽기 전용으로 받는다. 입력 폴더가 하나인 것은 같으므로 판이 그대로다 |
| 표시·보고 | 실행 화면에 자료 이름·크기·해시 앞자리. 보고서 `a1-draft-report/4`의 `input.sources`. 내용은 원장에만 두고 화면·보고에는 싣지 않는다 |

수동(원본 앱) 참여자는 같은 질문 본문(목록·해시 포함)을 받고 파일은 사용자가 직접 첨부한다. 실제로 첨부했는지는 확인하지 못한다(K21).

## 3. 실제 실행

준비: 새 원장 `dml-live-b-20260924`(시작 전 없음), 설정의 상한은 Codex 1·Claude 2(전체 3, 원장에 고정). Claude 1회는 C(실제 합성)가 같은 실행을 쓰도록 남긴 몫이다. 두 provider에 빈 입력 폴더를 따로 두었다. [#39의 manifest](../2026-09-24-windows-live-completion/manifest.v2.json)로 무모델 준비 조회(`--check-config`)가 둘 다 허가했다: 판 `codex@8a0128d4c791`·`claude-code@126be128bed7` 그대로, 설치판 0.156.1·2.1.280, 문맥 미확인 opt-in. 조회는 원장을 만들지 않았다.

자료는 합성한 “가상 회사 원격 근무 규정” 한 파일(`policy.md`, 295 bytes)이다. 질문은 그 규정의 주당 원격 근무 횟수와 신청할 수 없는 때를 묻고, 첫 줄에 자료의 확인 표식을 적게 했다. 개인 자료·외부 도구·인터넷은 쓰지 않게 했다. 정책은 `include_unverified`, 최소 2명.

## 4. 한계와 남은 것

- 한 질문·한 합성 파일이다. 긴 자료·여러 파일·이진 파일·자료가 지시문처럼 쓰인 경우(프롬프트 주입)는 보지 않았다.
- “읽었다”의 근거는 답의 인용이다. 참여자가 어떤 도구로 몇 번 읽었는지는 결과 요약에 남기지 않는다.
- 자료 폴더 경로(임시 폴더)가 질문 본문에 들어간다. 개인 경로는 아니지만 실행마다 달라 입력 digest도 실행마다 다르다.
- 시도 도중 폴더를 바꿔치기하는 것(K14)은 막지 못한다. 시도 사이의 변경만 시작 전에 막는다.
- 원장 `dml-live-b-20260924`는 Claude 1회가 남은 채 보관한다. C의 실제 합성은 이 공개된 실행을 쓴다.
