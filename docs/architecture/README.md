## 유지한 원칙과 수정한 우선순위

코드가 권한·운영 규칙을 관리하고 모델은 작업/좁은 판단을 담당하며, 독립 검증을 거친 결과만 수용한다는 원칙은 유지합니다. JSON 통신과 토큰 절약, 모델 확신과 승인 권한을 구별하는 점도 그대로입니다.

수정한 것은 초기 구현의 크기와 비교 기준입니다. 자체 scheduler·SQLite를 무조건 먼저 만드는 대신 Symphony의 명세/참고 구현을 적합성 시험합니다. task 상태 소유자는 하나로 유지하고 run journal은 증거·비용을 기록합니다. 경제성 실험은 작은 고정 하네스에서 수행하며 저가 단독·기존 router와도 비교합니다. Jev의 의미 검색과 read-only 문맥 선택을 작은 실험 지점으로 추가했습니다.

구체 결정이 겹치면 v0.2를 현재 제안으로 읽습니다. v0.1은 삭제하지 않은 설계 이력이며, 초기 가정이 모두 사용자 확정 요구가 된 것은 아닙니다.
