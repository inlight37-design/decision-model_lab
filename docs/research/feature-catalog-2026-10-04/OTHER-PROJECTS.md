# 다른 프로젝트에서 꺼내 쓸 기능

[목록 입구](README.md) · [출처·판본](SOURCES.md) · [우리 앱으로 묶기](APPLICATIONS.md)

Hermes와 겹쳐도 출처별 장점을 남겼다. 이름이 비슷하다고 같은 구현으로 합치지 않는다. “후보”는 미구현 제안, “부분”은 현재 앱에 기반이 있는 기능이다. 공식 제품 기능, 이전 세션의 조사, 이번 코드 확인은 [출처표](SOURCES.md)에서 구분한다.

## 기능 선택 때 제품 이름보다 볼 것

- **비슷한 기능의 차이:** Hermes 검색은 대화 원문 탐색, AnchorMind는 구조화된 장기 기억 검색, WorkTrail은 작업 판단·증거의 인계다. 하나의 “메모리”로 합치면 필요한 흐름을 놓친다.
- **도입 방식:** 화면/운영 원리 참고 → 기존 코드로 작은 구현 → 모듈 재사용 → 공식 인터페이스 연결 → 외부 제품 운영의 순으로 선택지가 있다. 뒤 단계가 항상 더 좋은 것은 아니다.
- **다시 검토할 때:** 범위가 커짐, 사용 불편 반복, CLI 판 변경, 계정/서비스 조건 변경, 검색 실패 사례 축적 같은 구체적인 계기가 있으면 해당 항목과 고정 출처를 열고 최신판을 비교한다.
