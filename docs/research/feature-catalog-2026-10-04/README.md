## 읽는 기준

- **현재:** 기준 main `6cfb78c5a91dc26a46d95229c89f6e2bbfb6830c`의 [기능 안내](../../FEATURES.md)와 코드에 대조했다. `부분`은 기반이 있지만 후보의 사용자 흐름까지 완성된 것은 아니라는 뜻이다. `후보`는 이번에 구현하지 않았다.
- **접점:** `앱`은 Decision Lab 사용자 기능, `개발`은 이 프로젝트를 만드는 AI의 작업 방식, `확장`은 실행 구조가 커질 때의 기능이다. 개발용 기억이나 작업판을 격리 참여자의 입력으로 자동 연결하지 않는다.
- **호출:** `0`은 해당 관리·화면 동작 자체에 추가 모델 호출이 없다는 뜻이다. 선택한 글을 입력에 붙이면 다음 호출의 입력량은 늘 수 있다. `추가`는 요약·조언·반복 실행 등 새 모델 호출이 든다. `외부`는 별도 도구·서비스·계정·장비가 필요할 수 있다.
- **노력:** 작음/중간/큼은 코드 접점을 보고 매긴 상대적 추정이며 일정이나 견적이 아니다.
- **근거:** 출처의 기능 설명과 우리 적용 제안을 구분했다. 공식 문서만 읽은 기능은 실제 실행으로 검증했다고 쓰지 않는다. 이름이 같아도 동일한 독립성·권한·과금 보장을 갖는 것은 아니다.

목록은 **Hermes의 고정 판 기능 안내 전체와 주요 사용자 흐름, 기존에 참고한 프로젝트**를 범위로 삼았다. 모든 외부 제품의 모든 플러그인·코드 분기를 감사했다는 뜻은 아니다. 확장 생태계는 종류와 찾을 입구까지 보존하고, 개별 설치 전 검토는 남겨 두었다.

## 이번 검토에서 달라진 판단

기존 Hermes HP-01–HP-10은 실행 경계와 단계별 도입 계획에 유용하지만, 사용자 편의 기능의 목록으로는 좁았다. 여기서는 그 순서 밖의 기능도 기록했다. **“지금 설치하지 않는다”와 “가져올 기능이 없다”를 같은 뜻으로 쓰지 않는다.**

가까운 후보는 저장된 팀 구성, 이전 실행 검색, 결과물 서랍, 대기·완료 알림, 자료 선택 편의다. 그 다음에는 스킬 묶음, 기억 관리 화면, 검토 후 수정 답변, 작업 흐름 양식이 있다. 자동 실행·원격 연결·외부 기억 서버도 버리지 않고 조건을 남겼다. 우선순위는 강제 순서가 아니며, 구체적인 사용 불편이 생기면 해당 항목에서 시작한다.

실제 기능 구현·외부 제품 설치·사용자 PC 접근·추가 구독 CLI/API 모델 호출은 하지 않았다. 기존 날짜 조사와 실행 계획은 그대로 유지했다. 이 목록이 PC 실측을 대신하지는 않지만, 대부분의 화면·데이터 모델·모의 흐름 설계는 클라우드에서 진행할 수 있다.
